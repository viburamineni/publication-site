# Content Model

The executable source of truth is the ordered migration set in
[contentful/migrations](contentful/migrations). Default locale is `en-US`; environment is `master`.

| Type              | Fields and frontend use                                                                                                                                                                                                                                                                                                                                                                                             |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Article           | Title, unique slug, dek, type, Rich Text body, hero Image, 1-3 Authors, primary Category, Topics, Book, Sources, related Articles, publication/updated dates, correction, previous slugs using the same lowercase-hyphen grammar as current slugs, featured, SEO, private internal notes, and a disabled/omitted publishing-check value managed by the sidebar app. Published entries build; drafts remain private. |
| Author            | Name, slug, photograph, title, short/full bios, coverage, social links, website, Staff/Guest, Active/Former. Powers bylines, staff, and archives.                                                                                                                                                                                                                                                                   |
| Category          | Name, slug, description, header Image, order, navigation toggle, controlled color token. Published categories marked for navigation automatically populate the site menu in display order.                                                                                                                                                                                                                          |
| Topic             | Name, slug, summary, hero Image, related Articles, timeline introduction, featured toggle.                                                                                                                                                                                                                                                                                                                          |
| Image             | Asset plus required alt text and credit, caption, rights note, focal-point description. Normalized into local responsive output.                                                                                                                                                                                                                                                                                    |
| Source            | Title, publisher, HTTP(S) URL, publication/access dates, note.                                                                                                                                                                                                                                                                                                                                                      |
| Book              | Title, author, cover Image, publisher, year, ISBN, information URL. Required by Book Review.                                                                                                                                                                                                                                                                                                                        |
| Homepage          | Optional advanced curation for lead, secondary, breaking, type sections, topic, category order, and announcement. Ordinary publishing does not require it; when it is absent, the homepage uses recent published stories, article types, featured topics, and Category display order.                                                                                                                               |
| Site Settings     | One-time publication identity: branding, optional logo/favicon/social image, footer/contact/social data, copyright, and launch switch. Keep exactly one entry published. Footer and contact URLs must be root-relative site paths or absolute HTTP(S) URLs.                                                                                                                                                         |
| Pull Quote        | Quote and attribution.                                                                                                                                                                                                                                                                                                                                                                                              |
| Fact Box          | Title and body.                                                                                                                                                                                                                                                                                                                                                                                                     |
| Related Articles  | Heading and article references.                                                                                                                                                                                                                                                                                                                                                                                     |
| Section Divider   | Named editorial divider.                                                                                                                                                                                                                                                                                                                                                                                            |
| Correction Notice | Correction text.                                                                                                                                                                                                                                                                                                                                                                                                    |

Rich Text allows paragraphs, H2/H3, ordered/unordered lists, list items, blockquotes, hyperlinks, inline Article links, and embedded Image/Pull Quote/Fact Box/Related Articles/Section Divider/Correction Notice entries. Arbitrary HTML and unsupported nodes fail the build with the entry ID.

The Article sidebar app enforces conditional editor rules that the Contentful model cannot express:
all types except News Brief require a published Hero Image entry, and Book Review requires a
published Book entry. The technical `publishingChecks` field is required but omitted from delivery
responses, so it does not enter the frontend normalizer or public output. Zod validation repeats the
same requirements at build time.

Any field/model change requires a new migration, schema/normalizer update, tests, this document, and an exported model snapshot.

# Publication fonts

This project self-hosts two SIL Open Font License 1.1 typefaces:

- `avara-bold.woff2` is used for article initials.
  - Designers: Raphaël Bastide, Wei Huang, Lucas Le Bihan, Jérémy Landes, and Walid Bouchouchi
  - Source: https://gitlab.com/velvetyne/Avara
  - File SHA-256: `aa8fe3cfd7dc03fd0e30d3bbec023469f4b3efdf17a72900a44a77e21e2472c8`
- `Chomsky.woff2` is used for the publication masthead.
  - Designer: Fredrick Brennan
  - Source: https://github.com/ctrlcctrlv/chomsky/releases/tag/v2.3
  - File SHA-256: `6d9f3d8686fef32b07a3770e0fcf2e987398a09610976dfc55e07aa0f18058a2`

The complete SIL Open Font License is linked from each upstream repository.
